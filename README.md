# BEYOND

BEYOND is a cross-platform learning and creation ecosystem designed for students, curious explorers, creators, and communities.

This repository contains the product foundation and interactive shell for the BEYOND experience.

## Current phase

Implemented in the current build:

- BEYOND identity and dark-first visual language
- role selector and role-based navigation
- responsive app shell for mobile-first flows
- Student workspace with learning, practice, memory, and explore surfaces
- Freedom workspace with discovery, skills, and create flows
- Open/community surfaces for learning and sharing
- structured topic and learning data model foundations
- extensible architecture for future knowledge graph, AI, and persistence layers

Intentionally deferred for later phases:

- full 330-topic knowledge library population
- full AI/provider integration
- community moderation engine and real file ingestion
- production persistence and account systems

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Build

```bash
npm run build
```

## Product direction

BEYOND is designed as a connected ecosystem rather than a simple classroom dashboard or chatbot. It composes:

- learning structure for students
- curiosity-driven exploration for broader understanding
- skill development and creation for personal capability
- shared knowledge and moderation for community learning
